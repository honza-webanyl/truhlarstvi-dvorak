# Truhlářství Dvořák

Ukázkový one-page web (Mode A — portfolio koncept Webanyl). React + Vite + Tailwind CSS.

## Spuštění

```bash
npm install
npm run dev
```

Produkční build:

```bash
npm run build
npm run preview
```

## Obsah

- Hero s Google hodnocením a CTA `tel:` / poptávka
- Služby & orientační ceník
- Galerie realizací (lightbox)
- Postup spolupráce
- Kontaktní formulář + údaje dílny

Design systém: `DESIGN.md`. Produktový kontext: `PRODUCT.md`.
